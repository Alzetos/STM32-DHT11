# Сервопривод SG90: подключение и работа по влажности

Дополнение к проекту от 30 октября 2026 года. Добавлено управление позиционным Micro Servo 9g типа SG90. На данный момент проверены сборки и модельные тесты; движение именно вашего сервопривода ещё нужно проверить на плате. Ранее пользователь подтвердил работу DHT11, TFT и потенциометра.

## 1. Назначение и алгоритм

STM32 получает относительную влажность φ из успешного пакета DHT11 и выбирает одну из двух команд:

| Ситуация | Команда |
|---|---|
| Включение питания или RESET | CLOSED — закрыть |
| Корректное измерение φ < 40 % | CLOSED — закрыть |
| Корректное измерение φ > 40 % | OPEN — открыть |
| Корректное измерение φ = 40 % | Сохранить предыдущую команду |
| Нет ответа, ошибка контрольной суммы, ошибка данных DHT11 | Сохранить предыдущую команду |

Если первое измерение равно 40 % или датчик отсутствует с момента включения, команда остаётся CLOSED. Если датчик отказал после открытия, команда остаётся OPEN. Старое значение влажности не используется для нового решения: в ServoControl_Update передаётся признак успешности текущего чтения.

Влажность хранится в десятых долях процента: 399 = 39,9 %, 400 = 40,0 %, 401 = 40,1 %. Порог равен 400. Значения выше 1000 отклоняются как недопустимые. Датчик опрашивается примерно раз в 2,2 секунды после завершения предыдущего обмена. После включения есть прогрев 2,2 секунды и время настройки TFT.

Гистерезиса и задержки подтверждения нет. Поэтому последовательность 39 %, 41 %, 39 % вызывает закрытие, открытие, закрытие. Правило сохранения при ровно 40 % не является полноценным гистерезисом.

## 2. Подключение

Сигнальный вывод — **PA6 / TIM3_CH1**, контакт 31 корпуса LQFP100. На плате берётся именно контакт с надписью PA6 на портовом разъёме PORTA. Не путать с номером физического контакта разъёма.

| Провод типового SG90 | Назначение | Куда подключить |
|---|---|---|
| Оранжевый или жёлтый | Управляющий сигнал | PA6 |
| Красный | Питание | +5 В отдельного стабилизированного источника |
| Коричневый или чёрный | Земля | Минус источника и GND платы STM32 |

Цвета типовые: проверить маркировку конкретного экземпляра. Для SG90 в документации указано питание 4,8 В, приблизительно 5 В. В качестве практического источника для одного малого сервопривода можно взять стабилизированный блок 5 В с запасом по току, например 1 А. Это запас источника, а не утверждение о постоянном токе привода.

Положительный вывод отдельного источника подключается только к питанию сервопривода; к шине питания платы его дополнительно не присоединять. Плата может продолжать питаться своим штатным способом. **Земля источника, сервопривода и STM32 должна быть общей.** Вывод PA6 формирует логический сигнал 3,3 В и не питает двигатель. На PA6 не подавать +5 В.

Перед подключением выключить питание. Первую проверку проводить без механической тяги: положение CLOSED является программной командой, и направление движения заранее не определено установкой качалки.

Настройки EasyMx:

1. Оставить единственную перемычку J8 в положении **PA4** для потенциометра P1. Положение PA6 не замыкать.
2. Отключить LED-нагрузку группы PORTA 0–7 / PORTA_L и внешние подтяжки PA6. Группа PORTB 0–7 для LED PB6 может оставаться включённой.
3. Не нажимать кнопку PA6 и навигационный джойстик: одно из его направлений также соединено с PA6. При работе таймера кнопка может замкнуть активный выход на землю.
4. Убрать внешние модули, подключённые к PA6, в том числе через разъёмы расширения. Не подключать к PA6 другой активный источник сигнала.
5. Настройки DHT11 на PB8, отключённой нагрузки PORTB_H и тачскрина DRIVEA оставить рабочими.

## 3. Два положения и калибровка

В App/Inc/monitor_config.h:

~~~c
#define SERVO_PERIOD_US 20000U
#define SERVO_HUMIDITY_THRESHOLD10 400U
#define SERVO_CLOSED_US 1000U
#define SERVO_OPEN_US 1500U
~~~

Период сигнала — 20 000 мкс, то есть 50 Гц. Внутри каждого периода линия PA6 находится в HIGH 1000 мкс для CLOSED или 1500 мкс для OPEN; остальное время — LOW. Импульсы продолжаются постоянно, в том числе при ошибке датчика, чтобы привод удерживал последнее заданное положение.

Эти значения задают два разных положения, а не измеренный угол заслонки. Связь длительности импульса с углом зависит от экземпляра сервопривода, установки качалки и механики. Значение 1500 мкс обычно соответствует средней области хода; оно выбрано для первого запуска без требования полного механического размаха. Вращение не обязательно составит ровно 90°.

Для настройки сначала проверить движение без тяги. Затем выбрать удобное закрытое положение, установить качалку и подобрать SERVO_CLOSED_US и SERVO_OPEN_US под механизм. После изменения собрать и прошить проект. Для изменения направления можно поменять значения местами. В текущем коде допустимы разные значения от 1000 до 2000 мкс; компилятор проверяет эти границы. Не добиваться положения через силовой упор: при гудении или заклинивании отключить питание и уменьшить ход.

Если при исправном питании привод не реагирует на 3,3-В сигнал, проверить паспорт именно этого экземпляра и уровни сигнала; совместимость неизвестного клона по входному уровню здесь аппаратно не проверена.

## 4. Настройки STM32CubeMX и таймера

| Параметр | Значение |
|---|---|
| Вывод | PA6, метка SERVO_PWM |
| Функция | TIM3_CH1, без remap |
| Режим канала | PWM Generation CH1 / PWM mode 1 |
| Полярность | HIGH |
| Частота входа TIM3 | 72 МГц |
| Prescaler | 71 |
| Counter Period / ARR | 19999 |
| Начальный Pulse / CCR1 в IOC | 1000 |
| Скорость GPIO | Low, Alternate Function Push Pull |
| Прерывания / DMA | Не используются |

При APB1=36 МГц и делителе APB1=2 таймер получает 72 МГц. Частота счёта равна 72 000 000 / (71 + 1) = 1 000 000 Гц, поэтому один отсчёт — 1 мкс. Период равен (19999 + 1) / 1 000 000 = 20 мс.

Счётчик TIM3 формирует импульсы самостоятельно, пока процессор читает DHT11, измеряет АЦП или рисует TFT. Главный цикл меняет только CCR1. TIM2 остаётся микросекундным счётчиком протокола DHT11; TIM4 остаётся генератором 1-кГц ШИМ светодиода PB6. Использовать для сервопривода соседний канал TIM4 с отдельной частотой нельзя: каналы одного таймера делят PSC и ARR.

Обновлены и IOC, и соответствующий HAL-код main.c / stm32f1xx_hal_msp.c. Для текущей сборки запуск CubeMX не требуется; регенерация нового IOC в графическом CubeMX в этой среде не выполнялась.

## 5. Файлы и функции

| Файл / функция | Что делает |
|---|---|
| App/Inc/servo_control.h | Тип ServoPosition, объявления функций |
| App/Src/servo_control.c | Выбор положения по влажности и запись CCR1 |
| ServoControl_Init | Проверяет ARR=19999, задаёт CLOSED, запускает PWM TIM3_CH1; ошибка настройки/запуска вызывает Error_Handler |
| ServoControl_Update(humidity10, reading_valid) | Ниже порога закрывает, выше открывает, при равенстве и ошибке сохраняет команду |
| ServoControl_GetPosition | Возвращает заданное положение: SERVO_CLOSED или SERVO_OPEN |
| ServoControl_GetPulseUs | Возвращает текущую длительность импульса в микросекундах |
| static set_position | Сохраняет команду, выбирает длительность и записывает CCR1 |
| Core/Src/main.c, MX_TIM3_Init | Настраивает TIM3, затем вызывает HAL_TIM_MspPostInit |
| Core/Src/stm32f1xx_hal_msp.c | Включает тактирование TIM3/GPIOA и настраивает PA6 как AF Push Pull без remap |
| Core/Inc/main.h | Макросы SERVO_PWM_Pin и SERVO_PWM_GPIO_Port |
| App/Src/monitor.c | Запускает контроллер до прогрева; после каждой попытки DHT11 передаёт данные и признак достоверности; выводит команду на TFT |
| App/Inc/monitor_config.h | Порог и длительности двух команд |
| Makefile и STM32Make.make | Включают servo_control.c в обе сборки |
| DHT11Monitor.ioc | Пин и настройки TIM3 для CubeMX |

На TFT используется ранее свободная строка 1: SERVO: CLOSED или SERVO: OPEN. Остальные строки сохраняются: TEMP, HUM, BUS, ADC, U ADC, U IN, LED, DHT11. OPEN/CLOSED — **заданное положение**, а не подтверждение движения. У трёхпроводного SG90 нет отдельного провода обратной связи для STM32.

## 6. Сборка и проверка

Проверены обе команды:

~~~sh
python3 tools/project.py build
make -j16 DEBUG=1 -f STM32Make.make
~~~

Для загрузки использовать существующий профиль ST-LINK в VS Code, затем Continue после остановки на main. При использовании Debug STM32 загружается build/debug/DHT11Monitor.elf; при профиле Build STM32 — build/DHT11Monitor.elf. Прошивка автоматически на плату не записывалась.

Модельные тесты:

~~~sh
python3 tests/run_servo_tests.py
python3 tests/run_led_tests.py
python3 tests/run_dht_tests.py
~~~

Новый тест компилирует настоящий servo_control.c с моделью HAL-таймера. Проверены все 1001 допустимое значение влажности из обоих исходных состояний, точное равенство 40 %, удержание при ошибках и недопустимом диапазоне, начальное закрытие, отсутствие перезапуска PWM при обновлениях и ошибки настройки/запуска таймера. Применяются -Wall -Wextra -Werror и UndefinedBehaviorSanitizer. Тесты LED и DHT11 также проходят.

Аппаратная проверка: при запуске ожидается CLOSED; при влажности больше 40 % — OPEN; после падения ниже 40 % — CLOSED. Если в помещении уже больше 40 %, после первого успешного измерения открытие нормально. Пропадание ответа DHT11 должно оставить последнее положение. На осциллографе ожидаются 50 Гц и HIGH 1,0 / 1,5 мс. Направление, реальный угол, питание под нагрузкой и уровни конкретного привода проверяются отдельно на стенде.
